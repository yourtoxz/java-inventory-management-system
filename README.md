# Java Inventory Management System

A Java-based inventory management system featuring product registration, search, stock updates, removal, and input validation.

Developed as a learning and portfolio project, focusing on object-oriented programming, clean code, exception handling, and software engineering best practices.

**Status:** In Development

## Technologies

- Java 11
- Maven
- JUnit 5

## Features

- Product registration
- Product listing
- Product search by code
- Stock quantity updates
- Product removal
- Inventory reports
- Input validation and exception handling
- Duplicate product code prevention

## Getting Started

### Prerequisites

- Java 11 or higher
- Maven

### Running the project

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd java-inventory-management-system
```

Compile the project:

```bash
mvn clean compile
```

Run tests:

```bash
mvn test
```
